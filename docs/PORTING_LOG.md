# 功能搬运记录

从现在开始，每搬完一个 Saleae / Logic 2 功能，都新增一份文档到 `docs/ported-features/`，并在这里追加索引。目标是让我们之后能快速回答四个问题：

- 这个功能参考了原版哪些文件？
- 本地改了哪些文件？
- 行为是否已经可运行？
- 和原版还有哪些已知差距？

## 记录规范

每个功能完成后创建：

```text
docs/ported-features/YYYY-MM-DD-功能名.md
```

文档必须包含：

- 功能范围
- 原版参考路径
- 本地落点文件
- 复用方式：资源复用、结构复刻、状态规则复刻、算法搬运或完全重写
- 用户可见行为
- 验证方式
- 已知差距 / 后续任务
- 对应 Git 提交

提交信息建议使用：

```text
port: 功能名
```

如果只是整理文档或版本管理，使用：

```text
docs: 说明内容
chore: 说明内容
```
