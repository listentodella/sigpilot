# 用户波形标注（第一版）

在波形通道上直接放置人工标注，用图形 + 常显短标题记录关键节点，无需打开右侧面板
就能读懂含义。这是**用户数据**，与解码器输出的协议标识分开存储与绘制。

## 用法

| 操作 | 方式 |
| --- | --- |
| 添加 | 在波形上右键 → **添加波形标注…**（也可在通道标签上右键，落在视口中央） |
| 编辑 | 双击图形，或选中后按 Enter |
| 移动 | 按住图形左右拖动（松手才提交，采集进行中不可用） |
| 删除 | 选中后按 Delete/Backspace，或用选中时的删除按钮 |
| 取消选中 | 点击空白处或按 Escape |

编辑器可设置短标题（必填）、图形、颜色、采样点与详细备注。备注通过悬停查看。

## 图形

六种描边图形：旗标、菱形、警告、叉号、圆点、方块。

**它们是描边而不是填充**，与解码器标识（填充、含 `1/0` 方框）在视觉上区分开，
避免把“人工怀疑异常”误读成“解码器确认错误”。详情面板与 tooltip 也标注
“人工标注 · 不属于协议解码结果”。

## 显示规则

- 按**通道 + 采样点**定位，缩放、平移、调整行高后仍贴在原处。
- 标题默认显示在图形右侧；靠近右边界时翻到左侧。
- 标题过密时只收起标题，图形保留；选中标注可完整查看。
- 采样点与通道在导入时被校验，越界或非法条目会被丢弃而不是破坏整份捕获。

## 持久化

- 保存为 `.pxl` 时写入 `user_annotations`；重新打开会恢复。
- 旧文件没有该字段时按空列表处理（`#[serde(default)]`），Saleae 导出同样兼容。
- 空列表不会写进 manifest，避免无意义膨胀。
- 裁剪数据时，落在被丢弃区间内的标注会被移除，其余标注重新换算采样点。

## 代码位置

| 文件 | 职责 |
| --- | --- |
| `src/lib/waveformAnnotations.ts` | 校验、裁剪、拖动换算、布局（纯函数） |
| `src/lib/waveformAnnotationDrawing.ts` | 六种图形的 Canvas 绘制 |
| `src/components/WaveformAnnotationsOverlay.tsx` | 覆盖层：定位、标题收起、悬停、拖动、选中、键盘 |
| `src/components/WaveformAnnotationEditor.tsx` | 编辑对话框（含焦点陷阱与 Escape） |
| `src/App.tsx` | 会话状态、右键入口、保存/打开接线 |
| `src/styles.css` | `.waveformAnnotation*` 样式 |

## 本版未包含

- 时间区间标注（整段模式高亮）。
- 自定义图形上传、标注模板与快捷键。
- 标注入库/检索，以及与时间光标之间的显式关联。
