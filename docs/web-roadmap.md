# Web 功能 roadmap

更新于 2026-11-19。

## 两条产品路线

| 路线 | 设备位置 | 执行位置 | 状态 |
| --- | --- | --- | --- |
| 远程工作台 | 现场主机的 USB | 现场 Rust 服务采集、解码与保存；浏览器交互 | 首版已实现，通过 Instabox Demo 验证 |
| WebUSB 本地工作台 | 浏览器所在电脑或手机的 USB | 浏览器缓冲采集、波形测量与导出 | [PXLogic 首版](webusb.md)已实现，通过 Instabox 模拟 USB 验证 |

远程版与 WebUSB 版共享桌面工作台、波形组件、精确坐标、领域模型和文件格式；设备接入分别通过现场服务与浏览器 USB 适配器完成。WebUSB 工作台也提供无需 USB 授权的浏览器 Demo 设备。

WebUSB 首版代码已实现，但公开 HTTPS 静态站点部署暂缓。目前只能在开发环境运行 `pnpm dev:webusb` 预览，尚无面向用户的公开网址；恢复发布时再配置静态托管和更新流程，不需要新增设备端采集服务。

## 远程版第一阶段

- 桌面中提供独立的远程服务设置，默认关闭。启用后生成访问码，可允许修改标记、允许远程采集，并撤销已连接浏览器。
- 服务使用独立端口，默认 `127.0.0.1:10532`；明确配置局域网监听地址或 HTTPS 反向代理的外部地址。MCP 端口及授权保持独立。
- 正式浏览器入口使用真实共享采集，不使用桌面预览数据。提供采集列表、二进制视口波形、精确样点标记、测量、协议查询及文件上传/下载。
- 浏览器缩放、滚动和游标独立；标记通过共享工作台提交，沿用采集身份、版本检查和请求重试机制。
- 远程采集复用桌面设备初始化与采集路径，包括 MCU 固件、FPGA bitfile 加载。采集任务独立于单次 HTTP 请求及浏览器连接。
- 事件流采用有界 HTTP 长轮询；断线恢复取得共享快照，慢客户端不能阻塞采集。波形按需请求、取消过期请求，限制像素、通道及解码页预算。
- 访问码只用于换取有时限的 HttpOnly 会话 Cookie；服务停用、重启或撤销客户端使原会话失效。校验 Host、Origin 和请求预算。
- Web API 只发布领域操作。桌面文件路径、终端、扩展执行和 MCP 管理不作为浏览器通用命令接口开放。

2026-11-18 在 Instabox 通过了 6 个 Rust 测试及浏览器端到端验证。两个独立授权的 Chromium 会话分别从回环地址和虚拟机的私有 IPv4 地址完成了测试。每次测试使用同一段 1 MHz、10048 个样点的 Demo 采集，验证了独立视口、样点 5 标记共享、断线重连、UART 查询跳转、文件保存重开、浏览器发起新采集和授权撤销。TypeScript、生产前端构建以及 Linux 桌面 Rust 编译检查均已通过。操作步骤和实测界面见[远程工作台](remote-workbench.md)。

下一项硬件验收是在两台独立主机之间通过实际 LAN/VPN 对 USB 设备运行持续采集，记录丢样、吞吐、内存与视口请求延迟。

## 后续远程能力

1. 完善完整桌面工作台的浏览器呈现、更多解码配置与分析结果/报告界面。
2. 从桌面采集适配器抽出无界面主机服务，复用相同 Web API；加入后台启动、自动保存、磁盘策略与故障恢复。
3. 公网部署的用户/项目权限、审计、控制权交接及多现场管理。
4. 更低带宽下的瓦片缓存、增量传输、可见通道调度及网络性能验收。

## WebUSB 后续阶段

已实现 PXLogic 运行态与 CH569 引导模式识别、用户授权、按系统配置 USB 接口、Worker 中的寄存器与 Bulk 传输、FPGA 临时加载、用户发起的 MCU 升级与重连，以及有界 DDR 缓冲采集。浏览器复用波形组件，可按样点测量、跳转边沿、导出桌面可读的 `.pxcap`。操作说明和验证范围见 [WebUSB 本地工作台](webusb.md)。

1. 在 Windows、Linux、macOS 上用已知信号源验证冷启动、驱动绑定、固件重新枚举、样点正确性和重复采集。
2. 移植可取消的长时捕获与有界内存保留；在明确分段采集和可能的窗口间隙后，再评估能否支持协议解码以及设备/浏览器实际 USB 链路速率限制。
3. 将协议解码运行时适配到浏览器，扩展 Android、离线缓存及其他 USB 设备后端。

WebUSB 不替代异地采集服务。上位机免安装与操作系统驱动免配置分别验收；不能把 USB 测速模式吞吐作为完整真实采集无丢样的验收结果。
